# WONDER WORLD BUSINESS HUB

A multi-business directory for the Wonder World network.

## Featured business

### VANSH CUISINE 360
Customer-facing restaurant digital menu and WhatsApp ordering enquiry app.

- 27 menu categories and 181 menu entries in the supplied menu data
- Search, category filters, sorting and cart
- Customer details and WhatsApp order request
- Party / function enquiry form
- Five visual themes and English/Hindi introduction toggle
- PWA manifest and offline cache support

## Open the projects

- Hub landing page: `index.html`
- VANSH CUISINE 360: `businesses/vansh-cuisine-360/index.html`

## GitHub Pages setup

Open **Settings → Pages**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save. After GitHub Pages publishes the site, the restaurant module will be available under `/businesses/vansh-cuisine-360/`.

## Customer order notice

This version prepares order and party enquiry messages in WhatsApp. It does not collect online payments or guarantee an order. Restaurant confirmation is required for availability, prices, delivery charges, date and final acceptance.

## Source organization

The restaurant's source files are kept inside `businesses/vansh-cuisine-360/`. The repository root is reserved for the business hub landing page and repository documentation.
